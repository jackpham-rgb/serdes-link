# data/touchstone/

`synthetic_12in_channel.s4p` is generated by `make_synthetic_channel.py`
(scikit-rf, two identical uncoupled lossy FR4 microstrip lines) — a
stand-in for a real measured board, not a measurement. Regenerate with:

```
python data/touchstone/make_synthetic_channel.py
```

When a real measured channel exists (Stage B — see the project howto in the
private planning repo), it goes here too, and `channel.load()` does not
change: it takes a path and nothing else. Cite the source of any non-synthetic
file (vendor eval board, public backplane data, etc.) right here in this
README when that happens.

Port map every file in this folder must follow: scikit-rf `se2gmm(p=2)`
native order — port 1 = TX+, port 2 = TX-, port 3 = RX+, port 4 = RX-. See
`src/serdeslink/channel.py` docstring for why this matters (getting it
backwards produces plausible-looking garbage, not an error).
